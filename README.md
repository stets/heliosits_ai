# Helios AI website

Static site hosted on GitHub Pages from `main` at `https://heliositservices.com/`.

## Preview

Run `python3 -m http.server 8080` and open `http://localhost:8080/`.
There is no build step. Pages use directory URLs supported by GitHub Pages.

## Consultation inquiries

The homepage and all three service pages link to `hello@heliositservices.com` with
a prefilled subject and inquiry outline. These links open the visitor's email app;
the visitor still needs to send the email. A plain email address is provided as a
fallback. Requests do not book a calendar slot or subscribe anyone to a newsletter.

FormSubmit is deferred pending the owner's choice. The proposed form, script, and
thank-you page are preserved in `_drafts/`, excluded by GitHub Pages' default Jekyll
build. No active page submits to FormSubmit or loads the draft form script.
If this provider is chosen later, activate the destination inbox and verify a real
submission, CAPTCHA, redirect, receipt, and Reply-To before publishing the form.

## SEO and measurement

The homepage and three distinct service pages have unique titles, descriptions,
canonical URLs, social metadata, structured data, and crawlable internal links.
`robots.txt` points to `sitemap.xml`. The sitemap includes the homepage and service
pages. Organization and service schema do not claim a physical address,
certification, reviews, pricing, or affiliation with Anthropic.

The available Search Console service account did not have access to this domain
at the October 12, 2026 check. Verify a property for this domain, share access with
the existing service account if desired, and submit the sitemap after publication.
GitHub Pages reported HTTPS enforcement disabled; check the certificate and enable
HTTPS enforcement in repository Settings → Pages when available.

No analytics service is provisioned by this change. Email subjects identify the
requested service, but the site does not currently measure visitor-to-inquiry
conversion. Assess search clicks and queries in Search Console alongside actual
inquiry emails. Record qualified inquiries, calls, proposals, and paid projects
separately. The target searches concern Claude implementation for small businesses,
AI workflow automation, and Claude team training; these targets are based on the
services offered and observed search intent, not measured keyword volume or rank.

The acquisition plan does not use the Facebook group. Avoid bulk blog expansion
until real query and inquiry data identifies a useful next topic.
